# Flaude — phone app

The built phone app of Flaude (a stand-up writing tool), published with GitHub Pages:
https://spartacusse.github.io/flaude-phone/

It holds no data. Passages and notes travel locked (AES-GCM) through a relay; only the paired phone
and computer have the key. The source lives in the Flaude repository (`apps/phone`); this repository
only receives its build.
